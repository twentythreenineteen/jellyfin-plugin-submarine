🌊 Submarine — Plex-Style On-Demand Subtitles

Submarine brings Plex-style on-demand subtitle discovery, virtual subtitle streams for every Jellyfin app (Roku, Android TV, Apple TV / Swiftfin, Fire TV, Kodi, Web, Desktop), and real-time multi-format subtitle conversion (SRT, VTT, ASS, SSA, SUB, TTML).

Universal Client & Web Player Integration

Injects on-demand remote subtitle candidates directly into Jellyfin's PlaybackInfo and ItemDetails responses so native TV and mobile clients can select and stream remote subtitles without a custom UI plugin.
Automatically injects the interactive Submarine search & live sync modal into the Jellyfin Web video player OSD and subtitle menu.

Languages, Formats & Provider Options

Example: eng,spa,fre,ger,jpn. Virtual subtitle streams will be queried for these languages when playback starts.
Maximum number of remote subtitle candidates to list in the player's subtitle track selector per language (recommended: 3–5).
Target subtitle format used when converting or saving subtitles on the fly.
